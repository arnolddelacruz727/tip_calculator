## What it does

- Takes a bill amount in a `TextField`
- Lets you pick 10%, 15% or 20% with a `SegmentedButton`
- Updates the tip and total right away with `setState`
- Shows "Enter a valid amount" when the input isn't a number
- Uses a Material 3 green theme from `ColorScheme.fromSeed`
